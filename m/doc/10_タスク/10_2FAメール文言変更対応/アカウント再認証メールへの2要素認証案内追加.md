# パスワード再設定メールへの2要素認証案内追加

## 要件

パスワード再設定メールに、2要素認証が未設定の場合に設定を促す案内を追加する。

- refery は今後の改修で2要素認証が必須となるため対象外。
- 今回のコード変更範囲は、medup-core-service内でメール本文を管理しているforo 連携マップ・foro 入退院調整・foro 逆紹介管理の3サービス。
- foro CRMはSendGridテンプレートが本文管理元のため、このコード変更には含めず、別途SendGrid側での更新が必要。
- 二要素認証設定用メールおよびログイン時の認証コードメールは対象外。

確認対象:

- `medup-core-service` (`/Users/medup005/Desktop/work/medup-core-service`)
- `foro-crm-api` (`/Users/medup005/Desktop/work/foro-crm-api`)

## 結論：変更箇所

| 調査対象 | パスワード再設定メールの管理方法 | 今回の修正箇所 |
|---|---|---|
| `medup-core-service` | CRMはB2CポリシーからSendGridを利用。他3サービスはNext.js API routeからResendを利用。 | **コード変更対象**: 連携マップ・入退院調整・逆紹介管理の3つの `forgot-password/send.ts`。CRMはコード変更なし。 |
| `foro-crm-api` | CRMのパスワード再設定メール送信・本文は確認できない。招待メールは別経路。 | 対象外。変更ファイルなし。 |
| SendGrid（リポジトリ外） | CRMパスワード再設定メール本文を管理。 | CRMにも同じ案内を適用する場合は別途更新が必要。今回のコード変更では未対応。 |

今回の変更は **`medup-core-service` 内の3つのメール本文**が対象です。CRMのSendGridテンプレートと`foro-crm-api`は変更していません。

`medup-core-service` 内の以下のファイルはCRMの送信方式と環境ごとのテンプレートIDを確認する参照資材であり、本文そのものの編集先ではありません。

- `packages/foro-adb2c-generator/src/custom_policies/CrmSignIn.xml.ejs`
- `packages/foro-adb2c-generator/src/custom_policies/CrmTrustFrameworkExtensionsWithCustomEmail.xml.ejs`
- `packages/foro-adb2c-generator/env/staging.json` と `packages/foro-adb2c-generator/env/production.json`

## 4サービスのパスワード再設定メール経路

| サービス | 送信経路 | 文面の管理場所 |
|---|---|---|
| foro CRM | B2CポリシーからSendGrid APIを呼び出す | SendGridの動的テンプレート（`crmSendGridTemplateId`） |
| foro 連携マップ | `forgot-password/send.ts` からResendを呼び出す | `apps/foro-outpatient-web/src/pages/api/admin/b2c/emails/forgot-password/send.ts` |
| foro 入退院調整 | `forgot-password/send.ts` からResendを呼び出す | `apps/acute-care-flow-web/src/pages/api/admin/b2c/emails/forgot-password/send.ts` |
| foro 逆紹介管理 | `forgot-password/send.ts` からResendを呼び出す | `apps/foro-op-optimizer-web/src/pages/api/admin/b2c/emails/forgot-password/send.ts` |

したがって、**CRMのみSendGridで本文管理しているという調査結果は正しい**。他3サービスはResendを使い、メール本文は `medup-core-service` 内の各API routeにある。

### 該当メールと送信元

提示されたメール文面は、foro CRMのパスワード再設定メールに該当する。CRMの送信経路は今回のコード変更範囲外だが、他3サービスにも同目的のパスワード再設定メールがあるため、今回のコード変更対象とした。

- [CrmSignIn.xml.ejs](../../packages/foro-adb2c-generator/src/custom_policies/CrmSignIn.xml.ejs) でパスワード忘れフローを定義し、`PasswordReset` に接続している。
- 親ポリシー [CrmTrustFrameworkExtensionsWithCustomEmail.xml.ejs](../../packages/foro-adb2c-generator/src/custom_policies/CrmTrustFrameworkExtensionsWithCustomEmail.xml.ejs) の `SendOtp` が、再設定用コードをSendGrid経由で送信する。
- `GenerateEmailRequestBody` が `otp` と `email` をテンプレートデータとして渡し、`crmSendGridTemplateId` のテンプレートを指定する。
- staging / productionのテンプレートIDは [`staging.json`](../../packages/foro-adb2c-generator/env/staging.json) と [`production.json`](../../packages/foro-adb2c-generator/env/production.json) の `crmSendGridTemplateId` に設定されている。メール本文はSendGrid側で管理されている。
- `foro-crm-api` の [`AccountMailer`](../../../foro-crm-api/app/mailers/account_mailer.rb) と `app/views/account_mailer/invitation_to_*.{html,text}.erb` は別のアカウント作成フローで送信する招待メール用。提示されたパスワード再設定メール本文を管理していない。

CRMのパスワード再設定メール本文の修正場所は **SendGrid上のテンプレート**。`medup-core-service` はテンプレートIDを参照し、`foro-crm-api` にCRM再設定メール本文はない。

### 2要素認証の設定状態について

パスワード再設定メールのSendGridテンプレートに渡すデータは、現在 `email` と `otp` のみ。2要素認証の設定状態は渡していない。この要件は、状態に応じてテンプレート表示を分岐するのではなく、「未設定の場合は設定してください」と受信者に案内する文面にすれば、追加の状態判定なしで満たせる。

## 今回のコード変更対象

- **foro 連携マップ**: `apps/foro-outpatient-web/src/pages/api/admin/b2c/emails/forgot-password/send.ts`
- **foro 入退院調整**: `apps/acute-care-flow-web/src/pages/api/admin/b2c/emails/forgot-password/send.ts`

アプリのメール送信ロジックや `enable-mfa/send.ts`、`check-mfa/send.ts` は変更対象ではない。
