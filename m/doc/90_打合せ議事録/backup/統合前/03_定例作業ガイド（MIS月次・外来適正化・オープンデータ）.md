# 定例作業ガイド（MIS月次・外来適正化・オープンデータ）

## 1. オープンデータ取り込みの全体像

メダップで扱うオープンデータは以下の3種類が存在し、定期取り込みの仕組みがあるのは「医科・歯科」と「ナビイ」の2種類である。

| データ種別 | 取得・更新方法 | 定期取り込み | 更新頻度・備考 |
| :--- | :--- | :---: | :--- |
| **厚生局の医科・歯科指定データ** | 月次公開。Data Ops担当が手動で取得・一部加工し、管理ツール（`admin-web`）からインポートして **MIS** 本番を更新。 | あり（手動＋ツール） | 毎月1回（詳細は「2. MIS 月次更新作業」参照） |
| **ナビイ（navii / 医療情報ネット）** | Excel/CSVでの公開形式がないため**スクレイピング**で取得。`data-management-api` 等のスクレイピング機能が自動実行しDBへ反映。 | あり（自動） | **毎週金曜日**に自動実行（`tmp_ref_naviis` 経由で `ref_naviis` へ反映） |
| **介護サービス情報公表システムデータ** | 当初は定期更新を想定しておらず**未自動化**。 | なし | 半年に1回（6月分が7月、12月分が1月2日）公開されるため、本来は更新が必要という認識。 |

## 2. 定例作業①：MIS 医科・歯科マスタ月次更新

### 作業概要
* **作業内容**：MIS 医科・歯科マスタの月次更新
* **所要時間**：約2時間
* **元データの格納先**：厚生局から取得したデータは **Google Drive** に格納している。
  * ファイル名例：`新規施設一覧_〇〇県_20201220.xlsx`
* **診療科のマッピング対応**：
  * 病院ごとに独自に命名される診療科名称について、システム上でどの検索カテゴリに分類するかは **手動で対応** している（管理ツールの「診療科」タブ / `department_mappings` 等で紐付け）。

### 実施スケジュール
| 項目 | タイミング・方針 |
| :--- | :--- |
| **厚生局のデータ公開** | 毎月 10日頃 |
| **作業実施タイミング** | 毎月 24日〜25日頃 |
| **デッドライン** | 明確な期限は設けていないが、顧客（病院側）には「月末頃」と案内している |

### 運用上の補足・判断が難しいケース
* **事業承継の判別**：
  * 元データに **旧機関コード** が記載されている場合は、「事業承継」であることが判別できる。
* **病院の名称変更（課題ケース）**：
  * 名称変更があった場合、データ上だけでは「単なる名称変更」なのか「閉院して新規開院した」のかの区別がつかない（厚生局への届け出方法に依存するため）。
  * **対応**：システム上で重複一覧が出力されるため、別途内容を確認し、統合（名寄せ・クレンジング）作業を行う必要がある。
* **住所変更・移転（課題ケース）**：
  * 住所変更や施設移転がある場合も同様に、同一施設かどうかの判断が難しい。

## 3. 定例作業②：foro 逆紹介（外来適正化）月次データ抽出

### 作業概要
* **目的**：高度急性期病院に通院している患者に対し、別の医療機関（近隣クリニック等）への通院を案内する（＝逆紹介する）ための **候補患者リストを月次で作成** する。
* **作業フロー**：
  1. 病院側から診療実績データを提供してもらう。
  2. 診療実績データをもとに用意されたクエリを実行し、翌月の予約データと突合して「来月の逆紹介候補リスト（作業リストのサジェスト）」を抽出する。
  3. 作成した外来適正化（最適化）用のファイルを、**CS（カスタマーサクセス）経由で顧客（病院）へ送付** する（※現在は手作業で実施）。

### 実施スケジュール
| 項目 | タイミング・管理方法 |
| :--- | :--- |
| **データ受領依頼** | 毎月 20日頃までに送付してもらうよう病院側へ依頼 |
| **アラート管理** | 毎月 20日にアラート設定（Googleカレンダーで予定日を管理） |
| **リスト抽出** | 20日の翌週（概ね月末）に逆紹介リストの抽出を実施 |

### 抽出結果の確認ポイント・今後の展望
* **診療報酬改定・乖離チェック**：
  * 基本は用意されたクエリをそのまま実行する想定だが、診療報酬改定に伴うコード変更等があるとクエリの修正が必要になる。
  * 抽出結果が前月データと大きく乖離している場合は、報酬改定等の影響を疑って調査を行う。
* **自動化の検討**：
  * CSからのファイル送付を含め手作業が発生しているため、今後は運用をルール化して自動化していきたい意向がある。
