# foundations

分類: ディレクトリ構成

### foundation層の構成

foundation 層は大枠の責務に応じて、コンポーネントをグルーピングしています

- Buttons (ボタンとして使われるもの)
    - Button
    - FileInputButton
    - TextButton
    - Chip
- Chart (チャートで使われるもの)
    - BarChart
    - BarChartTooltip
    - LineChart
    - ChartPagination
- DataDisplay (情報の表示として使われるもの)
    - Card
    - Img
    - Label
    - Tag
    - Tooltip
    - TooltipList
- FeedBack (ユーザーのアクションに対して使われるもの)
    - LoadingCircle
    - Toast
- Layout (レイアウトとして使われるもの)
    - CenteringContainer
    - Divider
    - Stack (縦並び)
    - Cluster (横並び)
    - Section (margin/padding取れる)
- Form (フォーム関連で使われるもの)
    - Checkbox
    - DatePicker
    - DateRangePicker
    - MonthPicker
    - ErrorMessages
    - Input
    - TextField
    - NumberInput
    - NumberInputField
    - Radio
    - RadioGroup
    - SelectBox
    - Textarea
    - TextareaField
- Navigation (ナビゲーションとして使われるもの)
    - Pagination
    - Tab
- Util (その他、便利UIとして使われるもの)
    - Accordion
    - ModalDialog
    - 🚧 Scrim (Backdrop との分離を行う)
    - Popover
    - PopoverMenu
    - SidePeak
    - Link (CSNのため)
