# 全共通ガイドライン

分類: コーディング

## 命名ルール

- コンポーネント
    - Presentationalコンポーネントは〇〇Presenter
        - （例）Task であれば TaskPresenter
    - リストは〇〇List、子要素は〇〇ListItem
- 術語目的語関係
    - `述語`が先、`目的語` が後
    - ◯AddHoge　×HogeAdd
- 要素の作成・追加
    - `Add` を使用
    - ◯AddHoge　×CreateHoge
- 要素の編集・更新
    - `Edit` を使用
    - ◯EditHoge　×UpdateHoge
- 要素の削除
    - `Delete` を使用
    - ◯DeleteHoge　×RemoveHoge
- 表示, 非表示を表す
    - `show` / `hide` で統一
    - （例） showModal / hideModal
- boolean を表す
    - `isHoge` で統一
    - （例）isShown / isChecked
- モーダル
    - Modal で統一
    - ◯Modal　×ModalDialog
- サイドピーク
    - SidePeakで統一
    - （例）HogeSidePeak
